# Typstbit

Generated by `moui` CLI 0.1.3 for module `local/typstbit` (template `counter`).

This is a standalone MoUI app. Prefer this project over cloning the full MoUI monorepo unless you are changing the framework.

## Versions

- CLI: `0.1.3`
- Default/framework dependency: `wzzc-dev/moui@0.1.9`
- These versions are independent: upgrading the CLI does not change the project dependency until you edit `moon.mod` / regenerate.

## Platforms

- `web`
- `linux`

## First run (~10 minutes)

```sh
moon update
moui doctor
moon run linux_skia --target native
moon build web_wasm --target wasm-gc
# serve web_wasm/ (static HTTP) and open index.html in a WebGPU browser
```

## Next steps

```sh
moon update
moui doctor
moon check web_wasm --target wasm-gc
moon run linux_skia --target native
```

## Project maintenance

- Add a platform later: `moui add platform <name> [--bundle-id ID]`
- Package inventory: `moui package` / `moui package --json`
- Safe doctor remediations: `moui doctor --fix`
