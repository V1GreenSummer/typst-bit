# Typst.bit MoonBit core

The MoonBit application core of [Typst.bit](https://github.com/V1GreenSummer/typst-bit),
an offline-first Typst document workbench. Published on mooncakes.io as
`V1GreenSummer/typstbit`.

Packages:

- `app`: pure application models and logic — command catalog and UI structure,
  palette filtering, outline parsing, multi-file project model, diagnostics
  mapping, package-spec scanning and theme planning (unit tested).
- `core`: wasm-gc exports of the above for the browser host (`core.wasm`).
- `typst_binding`: typed host binding for the compiler ABI (wasm host imports
  for the browser, native stubs for the CLI).
- `native_cli`: native Typst.bit CLI and MCP server; links against the Rust
  `typst-abi` static library (built from the main repository, see
  `tools/build-native-cli.sh`).
- `web_wasm`: the legacy MoUI canvas shell and the DOM workbench assets
  (JavaScript, plugins, styles) served by GitHub Pages.

## Versions

- CLI: `0.1.3`
- Default/framework dependency: `wzzc-dev/moui@0.1.9`

## Platforms

- `web`
- `linux`

## First run (~10 minutes)

```sh
moon update
moui doctor
moon run linux_skia --target native
moon build web_wasm --target wasm-gc
# serve web_wasm/ (static HTTP) and open index.html in a WebGPU browser
```

## Next steps

moon update
